# Optical Santa Ana - E-commerce & Probador 3D

Plataforma digital para **Optical Santa Ana** (Paraguay):
- Catálogo de armazones y accesorios.
- Visor 3D interactivo en 360°.
- Probador Virtual con IA (Virtual Try-On / VTO) en vivo y por selfie.
- Configurador de lentes recetados (OD / OI) y filtros.
- Información de Casa Central (Ruta 1) y Sucursal 2 (Ruta 2).
